The desktop scanner only runs while Counter-Strike is already open — it attaches to a live hl.exe.

Get the latest release Need help?

Release artifacts are published on GitHub with a SHA-256 checksum. If no release is listed yet, the project is still in development.

Requirements

Operating system

Windows 10 or 11, 64-bit.

Game

Counter-Strike 1.6 (hl.exe / cstrike.exe).

Rights

Administrator recommended for the deepest memory and process evidence.

Server

A reachable ACS web deployment (api.php) and its upload token.

Install

  1. Download ACS-Scanner-1.0.8-windows.exe — the whole app is this one file — and put it anywhere, e.g. C:\Tools\ACS.
  2. Configure acp-settings.json next to the executable, or in %APPDATA%\LongHorn ACS\, with your apiUrl and apiToken.
  3. Start Counter-Strike 1.6 and join a server (or stay at the menu).
  4. Run the scanner, press Scan, and let it finish — the signed report uploads automatically.
Example configuration: { "apiUrl": "https://your-host/acp/api.php", "apiToken": "YOUR_TOKEN" }

Verify the download

Each release publishes a SHA-256 checksum. On Windows:

Get-FileHash .\ACS-Scanner-1.0.8-windows.exe -Algorithm SHA256

Compare the result against the value in the release notes before running the app.
