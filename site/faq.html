Frequently Asked Questions

What ACS is, how it works, how to use it, and how your data is handled.

How it works

  1. Scan. With Counter-Strike running, the desktop app reads the live game process — modules, memory, hooks, files, drivers and configuration.
  2. Upload. Findings are packed into a report and signed (HMAC-SHA256) so they cannot be edited or swapped in transit.
  3. Review. The dashboard stores the report, classifies each artifact, and separates confirmed detections from lower-confidence review items.

What it scans

Processes

Running processes compared against a known cheat/tool list, with paths and hashes.

Drivers

Loaded kernel drivers with hashes, publisher and signature state.

Game modules

Every DLL mapped into the game, its path and signer.

Memory

Private executable memory that backs no file on disk.

Hooks & patches

Engine code compared byte-for-byte against the file on disk.

External readers

Processes holding handles on the game, foreign threads, overlay windows.

Scripts & config

Alias graphs and control-flow shapes behind bunny-hop, rapid-fire and no-recoil scripts.

Game files

The live game folder with hashes, so altered files and dropped DLLs are visible.

Build & client

Steam, non-Steam and community clients identified so they are not mistaken for cheats.

Using the app

  1. Put acp-settings.json (with apiUrl and apiToken) next to the executable, or in %APPDATA%\LongHorn ACS\.
  2. Launch Counter-Strike 1.6. The scanner only runs while the game is open.
  3. Press Scan and keep the game focused while the live-behaviour stage runs.
  4. The signed report uploads automatically when the scan finishes.
Tip. Run as administrator for the deepest evidence — some memory and process reads are limited without it.

Using the web dashboard

  1. Dashboard. Browse the newest scans, search by player or server, and filter to one server with a click.
  2. Report. See the verdict, player/server data, confirmed detections and review evidence.
  3. Evidence. Open a detection's forensic drawer for the exact rule and byte difference.
  4. Share / Compare / Export. Copy a single-report link, compare two reports, or export a PDF.

How safe is it?

Read-only

It collects and explains; it does not ban, punish or modify your game.

No password

It reads the SteamID the game already exposes — never your Steam password.

Tamper-evident

Reports are signed; edited reports are rejected when the server enforces signatures.

Masked IP

Addresses display with the last octet hidden (e.g. 109.187.61.***).

Gated access

Reports are stored outside direct web access and require a token or share key.

Fewer false positives

Known clients are recognised and common files are learned as clean.

Common questions

Is the scanner a virus or malware?
No. It is a read-only inspection tool. It opens the game process to read memory, hashes files and uploads a report — it does not inject code, modify the game, or run in the background.
Does it ban players automatically?
No. ACS produces evidence. A confirmed detection is strong evidence; every ban or kick is a human operator's decision.
Will it flag Steam, Discord or MSI Afterburner?
That is what client profiles and the artifact corpus prevent. Known overlays and injectors are recognised by name and hash, and common files seen on many machines are learned as clean.
Does it work with non-Steam clients and emulators?
Yes — NextClient, GSClient, GoldClient, RevEmu/RevCrew, SmartSteamEmu and Goldberg are identified so their own engine changes are not treated as cheating.
Do I need administrator rights?
The scan runs without elevation, but running as administrator allows deeper inspection and more complete evidence.
Does the game have to be running?
Yes. The scanner attaches to a live hl.exe — start Counter-Strike first.
How long does a scan take?
Typically well under a minute for the static checks, plus a short live-behaviour sample while you play.
What data is stored, and for how long?
Player identity, masked IP, OS, hardware identifiers, game build and the evidence found. Reports stay on the operator's server until an administrator deletes them. See the Privacy Policy.
Can a report be faked or edited?
Reports are HMAC-SHA256 signed. When the server enforces signatures, a report changed after signing is rejected.
Who can see my report?
Admins with the access token, anyone holding a single-report share link you give out, or localhost on the host machine.
Is there a way to prove I am clean?
Yes. Run a scan and share the resulting report link. A clean verdict is exactly the proof the system is built to provide.
I found a false positive — what should I do?
Send the report link to support. Legitimate programs are folded into the client profiles or classified clean in the corpus, fixing the false positive for future scans.
