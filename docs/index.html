02 / YOUR DATA, YOUR DECISION

Know what a scan can see.

01

Read the disclosure.

Before each scan, ACS shows the configured server and explains access to processes, modules, drivers, game files, memory evidence and activity traces.

02

Inspect the report.

Reports can contain player and device identifiers, paths, hashes, memory strings, game/server information, findings and timing. The complete JSON is shown before upload.

03

Choose whether to send.

Upload sends the report to the displayed operator. Declining keeps the report from being sent. The earlier rule download still exposes your IP address to that server.

Server access and retention are operator-controlled.

Records may remain until the operator deletes them. Ask about private access, retention and deletion before scanning. The public beta includes no production endpoint or API secret.

04 / COMMON QUESTIONS

Before you start.

Why is the scanner source private?

The maintainer distributes compiled releases while keeping detection implementation private. Public documentation describes data access and limitations. Private source does not prevent reverse engineering, and is not proof of safety.

Does it run continuously or install a driver?

The public package is an on-demand desktop scanner. It does not include the optional server plugin or driver scaffold and installs no background service. Continuous server gameplay analysis is a separate deployment.

Does a clean scan prove someone is not cheating?

No. A scan is a bounded observation. Unknown cheats, unavailable inspection surfaces and evasion can affect results. Warnings and detections need review before enforcement.

Where do I get the report server settings?

Ask your game-server operator for their HTTPS API address and any required credential. The public package has an empty configuration. GitHub Pages hosts this information site, not the private report API.

Is this endorsed by Valve, Microsoft or GitHub?

No. Counter-Strike and other product names identify compatibility targets. Hosting on GitHub and bundling Microsoft runtime files do not imply endorsement.
